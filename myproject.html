🏦 VaultUp – Secure Goal-Based Savings & Investment Platform

VaultUp is a secure, goal-based financial management platform designed to help users save 💰, invest 📈, and access loans 🏦 in a structured and disciplined manner. The platform combines customizable savings vaults, stock market investment options, and loan services into a single ecosystem, ensuring financial growth, security, and accessibility for all users, including minors 👨‍👩‍👧‍👦 under parental supervision.

📄 Abstract

VaultUp is a modern FinTech platform that enables users to efficiently save, invest, and manage their finances through customizable digital vaults 🔐. Users can create goal-based vaults for purposes such as education 🎓, travel ✈️, or emergencies 🚑, with optional lock-in periods for interest-based growth. The system also provides stock market investment vaults managed by financial experts and a loan application module for users seeking financial assistance. Security is ensured through RBI-compliant practices, two-factor authentication, and encrypted transactions 🔒.

🎯 Objectives & Goals

The primary objective of VaultUp is to build a goal-based digital savings ecosystem that promotes disciplined financial behavior. It enables users to manage savings vaults aligned with personal financial goals, apply flexible lock-in mechanisms for higher interest returns, and access investment opportunities under expert management. The system emphasizes financial security, regulatory compliance, and a seamless user experience while encouraging financial literacy and responsible saving habits 📘.

⚙️ System Overview

VaultUp automates savings, investments, and financial reporting based on user-defined inputs such as bank details, savings schedules, transaction history, and financial objectives. The system automatically transfers savings, updates wallet balances, manages investments, and generates detailed financial reports 📊, reducing manual effort and improving financial discipline.

✨ Key Features

  • 🎯 Goal-based savings vaults with flexible lock-in options
  • 🤖 Automated savings and smart fund allocation
  • 📈 Stock market investment vaults with expert management
  • 🔐 Secure transactions with encryption and multi-factor authentication
  • 👨‍👩‍👧 Parental supervision support for minors
  • 📲 Real-time financial insights and notifications

✅ Conclusion

VaultUp bridges the gap between savings, investments, and financial security through a single, goal-driven platform. By combining automation, strong security, regulatory compliance, and user-centric design, VaultUp empowers users to achieve financial stability, encourages long-term savings habits, and supports inclusive financial growth in modern digital environments 🌍.

🧠 Employee Burnout Detection & Productivity Monitoring System

This project is an Employee Burnout Detection and Productivity Monitoring System designed to automatically track real-time employee activity, calculate productivity 📈 and burnout scores 🔥, and provide meaningful insights to employees, HR, managers, and leadership for early intervention and improved workplace well-being.

🔐 The system begins with a secure login mechanism where each user enters valid credentials. Based on the assigned role, users are redirected to the appropriate dashboard while their login session is securely recorded in the database for auditing and transparency.

⌨️🖱️ Once logged in, employees are monitored in a non-intrusive and ethical manner through passive activity tracking such as mouse clicks, keyboard presses, movement, and active minutes. This data is collected continuously on the frontend and transmitted to the backend every 60 seconds for processing.

⚙️ The backend aggregates activity over short time windows and applies a human-centric algorithm that normalizes effort, increases productivity gradually with consistent engagement, and adjusts burnout very slowly to avoid unfair penalties. Short idle periods do not negatively affect scores, ensuring realistic and fair evaluation.

👤 Employees have full transparency into their own data. They can view productivity scores, burnout scores, burnout levels, login and logout times, daily productivity history, and detailed minute-wise activity logs. This promotes self-awareness and accountability without creating stress or surveillance pressure.

👥 HR users are assigned specific employees and can monitor only those employees through a focused dashboard. Features include searching, sorting by productivity, and visual burnout indicators, enabling HR teams to detect early warning signs and take supportive, preventive actions rather than reactive ones.

🏗️ Managers act as structural controllers within the system. They can create employee and HR accounts, assign employees to HRs, and manage organizational relationships. Managers are intentionally restricted from viewing sensitive behavioral analytics, ensuring ethical access control and data privacy.

🧩 The HRO role provides higher-level oversight by displaying all HRs along with the average productivity of employees under each HR. Drill-down views allow leadership to compare teams, balance workloads, and make strategic decisions based on aggregated performance data.

🗄️ On the backend, the system is implemented using FastAPI and SQLite with carefully designed database tables for users, sessions, live activity, daily productivity snapshots, and HR assignments. This architecture ensures secure role-based access, accurate session tracking, and consistent analytics across the platform.

✅ Overall, this system transforms burnout assessment from a manual and subjective process into a data-driven, fair, and preventive approach. It improves employee well-being, enhances productivity, supports HR and leadership decision-making, and promotes a healthier, more sustainable work culture suited for modern organizations.

📊 Business Decision Intelligence Platform (BDIP)

📌 Complete System Explanation

🔍 Overview

The Business Decision Intelligence Platform (BDIP) is a role-based, full-stack enterprise analytics system designed to support structured decision-making across multiple organizational levels. The platform integrates operational data, human resource metrics, and financial indicators into a unified system to deliver actionable, data-driven insights.

🔐 System Initialization & Secure Authentication

On first launch, the backend automatically initializes the database and seeds two permanent system-level users: the System Administrator and the Main Manager. These protected accounts cannot be modified or recreated through the UI, ensuring system integrity. Authentication is handled using JWT-based security, where each successful login generates a secure token containing the user’s role and identity.

🛠 Administrator Role

The Administrator configures the organization by creating managers, employees, and executives. Managers are created with a mandatory department, employees are assigned via dropdown selection and automatically inherit the manager’s department, while executives are created solely for analytics access. System-level users remain hidden from the admin interface for enhanced security.

👥 Manager Role

Managers can view only their assigned employees and update productivity and burnout scores within a validated range. The dashboard provides a live team overview including department details, performance scores, and automatically calculated burnout risk levels, enabling proactive and informed team management.

👤 Employee Role

Employees have a read-only dashboard displaying their department, productivity score, burnout score, and burnout risk level. This approach promotes transparency and self-awareness while preventing any unauthorized data manipulation.

💰 Main Manager Role

The Main Manager is responsible for revenue management and strategic oversight. Revenue is entered using structured units such as hundreds, lakhs, or crores and stored in a standardized format. The Main Manager also monitors manager-level performance using average team productivity and employee count.

📈 Executive Role

Executives consume high-level analytics without modifying any data. The executive dashboard computes an Overall Business Health Score using weighted revenue, productivity, and burnout metrics, supported by intuitive visual indicators and clear status classifications.

🧠 Intelligent Recommendations

Based on real-time system metrics, BDIP dynamically generates strategic recommendations such as burnout intervention plans, productivity improvement actions, and scaling guidance for high-performing teams.

🌐 System Value

BDIP bridges the gap between operational data and executive decision-making while maintaining strict role separation and security. The platform is scalable, secure, and aligned with real-world corporate workflows, making it ideal for enterprise environments, internships, academic evaluation, and professional demonstrations.

🌾 Smart Farming AI Assistant

AI + Weather + Mandi Rates for Farmers 🚜

This project is a Flask-powered AI backend designed to assist Indian farmers with real-time, localized agricultural information.

It integrates AI intelligence, weather forecasting, location services, and mandi rate updates to deliver actionable insights in multiple Indian languages.

✨ Key Features

  • 📍 Location-based weather updates (temperature, rainfall, wind speed)
  • 🗺 Accurate city detection using OpenStreetMap
  • 🤖 AI-powered query handling with GPT4All
  • 📊 Mandi (wholesale market) price information for major crops
  • 🌐 Multi-language support (English, Hindi, Marathi & more)
  • 🧑‍🌾 Professional, farmer-friendly advisory responses

🛠 Tech Stack

  • Flask & Flask-CORS – Backend framework
  • GPT4All – AI response generation
  • Google Translate API – Multi-language support
  • Open-Meteo API – Real-time weather data
  • OpenStreetMap API – Location detection

📌 Use Case

Farmers can ask questions like:

  • “आज प्याज का मंडी भाव कितना है?”
  • “What should I sow this season?”

The system instantly provides accurate, localized, AI-driven answers, making it ideal for smart agriculture solutions.

🔗 Perfect for: Smart agriculture apps, farmer advisory platforms, and agri-tech startup solutions.

🔐 User Authentication & OTP Verification System

The User Authentication and OTP Verification System is a secure web application designed to facilitate user registration, login, and verification using One-Time Passwords (OTPs) 📩. Built using Flask, this project demonstrates best practices in user data handling, authentication workflows, and web security fundamentals.

📌 Project Overview

This application provides an intuitive and responsive interface for managing user authentication and verification processes. Developed using Flask, a lightweight Python web framework 🐍, it enables users to register, log in, and complete identity verification via OTP. An Admin Dashboard is also included to monitor users and manage application data efficiently.

🎯 Objectives

  1. 👤 User Management: Enable users to create and manage secure accounts.
  2. 🔑 Authentication Process: Implement a strong login mechanism with OTP-based verification.
  3. 📊 Admin Dashboard: Provide administrators with visibility into user data and activity.
  4. ⚠️ Security Awareness: Demonstrate common security risks through an intentionally insecure login route.

✨ Key Features

  • 📝 User Registration: Collects essential details such as name, DOB, email, password, and mobile number.
  • 🔐 Secure Login: Validates credentials before triggering OTP verification.
  • 📨 OTP Verification: Sends OTP via email to complete the login process.
  • 🛠 Admin Dashboard: Allows administrators to view and monitor registered users.
  • 💉 Insecure Login Route: Demonstrates SQL Injection vulnerabilities for educational purposes.
  • 📱 Responsive Design: Built with Bootstrap to ensure smooth experience across devices.

🧰 Technical Stack

  • ⚙️ Backend: Flask (Python Web Framework)
  • 🗄 Database: SQLite with SQLAlchemy ORM
  • 📧 Email Services: SMTP for OTP delivery
  • 🎨 Frontend: HTML, CSS, JavaScript, Bootstrap

🚀 Future Enhancements

  • 🔒 Password Hashing using industry-standard algorithms
  • 🛡 Integration with Flask-Security or similar security modules
  • 👥 Role-Based Access Control (Admin, User, Moderator)
